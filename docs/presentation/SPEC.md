# Formula Search presentation specification

GOAL: A reader understands how a notation query becomes a saved occurrence in the
original paper, then can find installation instructions.

OUTPUT: HyperFrames, 1920 x 1080, 30 fps. 32 seconds / 960 frames. Separate 1600 px
README illustrations, 1280 x 640 social card, and a short muted GIF preview.

LOOK: #eef4f2 ground, #142d29 ink, #086f64 accent, white product surfaces. Inter
700 display at 88 px, body Inter 400 at 32 px, 96 px canvas margins. Rectangular
paper geometry with 16 px corner radii, 1 px separators, shadows 0 20px 56px at
9% opacity. No texture, gradient, glow, tilt, perspective, or decorative HUD.

OBJECTS: Genuine extension capture, original two-page example, actual result
cards, actual page filter/bookmark, original PDF excerpt, existing extension icon.
Conceptual architecture is labelled separately from screenshots.

MOTION: Product entrance 18 frames power4.out; camera reframing 21 frames
power2.inOut; graphic accent draw 15 frames power2.out; scene exits 9 frames.
Titles stop when landed. One principal motion at a time. Original product
recording uses normal playback speed; source offsets are recorded in edit.json.

SHOTS:
- Frames 0-119: Original equation and notation; result-first hook. Hero equation
  is a direct high-resolution render of the original example PDF.
- Frames 120-329: Live search, two occurrences, then page filter. The same w^2
  enters the real panel. Larger cropped view establishes the result evidence.
- Frames 330-599: Bookmark interaction and original excerpt, using the same live
  recording at normal speed; explanatory text remains stable while UI acts.
- Frames 600-779: The original excerpt returns to the paper; the actual saved
  occurrence is enlarged separately. Clear label: editorial close-up.
- Frames 780-959: Actual dark appearance alongside the end card, installation
  route and local-backend fact. Final title held at least 2 seconds.

BANNED: Invented UI or data, fabricated speed comparisons, fake Chrome side panel,
unavailable native overlays, testimonials, placeholder stars, narrow video inside a
large empty canvas, tilted screens, gradient/glow decoration, body text below
28 px when essential, moving titles while reading, assistant branding.

QA: Check starts/midpoints and cuts at 3.9/4.1, 13.9/14.1, 19.9/20.1,
25.9/26.1 seconds. Verify all source video offsets, original capture assertions,
font loading, static images at README width and 360 px, H.264 output 1920 x 1080
32 seconds, caption transcript, links, clean package hashes and production receipt.
