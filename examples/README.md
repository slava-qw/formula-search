# Formula playground

`formula-playground.pdf` is an original two-page demonstration document created
for this project. Its editable source is `formula-playground.tex`. These are
illustrative equations, not claims of research novelty.

Open the PDF in Chrome and search `QK^T` or `w^2`. These exercises use real PDF
text extraction, with no seeded results or model recognition.

Rebuild with `tectonic examples/formula-playground.tex --outdir examples`, or a
TeX installation providing `amsmath`, `amssymb`, `geometry`, and `xcolor`.

Original example text and TeX use the repository's MIT license. Embedded fonts
retain the TeX distribution's Computer Modern and Latin Modern terms; see
`licenses/` at the repository root.
